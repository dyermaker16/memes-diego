# memes-diego

Repositorio de soporte para la generación automática diaria de memes de "La Factoría de Memes" (Facebook) y el proyecto de TikTok de Diego.

- `sources/` — banco de imágenes base (de Pinterest) para armar memes.
- `memes/` — memes ya generados, con fecha, listos para publicar.
- `used.json` — registro de qué imágenes de `sources/` ya se usaron, para no repetir.
